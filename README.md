# Programming Skills Portfolio — Assessment 1

This repository contains three C++ challenges for the Programming Skills Portfolio assessment.

## Project structure

- Challenge 1 - CO2 Calculator: Programming Skills Portfolio/Challenge 1 - CO2 Calculator/main.cpp
- Challenge 2 - Joke Program: Programming Skills Portfolio/Challenge 2 - Joke Program/main.cpp and randomJokes.txt
- Challenge 3 - Book Manager: Programming Skills Portfolio/Challenge 3 - Book Manager/main.cpp and bookData.txt

## Build and run on Windows

Install a C++ compiler such as GCC. Open a terminal in the folder for the challenge you want to run, then compile and launch it:

    g++ -std=c++17 main.cpp -o challenge.exe
    .\challenge.exe

Run Challenges 2 and 3 from their own folders so the programs can find their data files.

## Challenge summaries

1. CO2 Calculator — estimates emissions from journey distance and fuel type using the values in the assessment brief.
2. Joke Program — loads jokes from a text file, shows each setup, then reveals the punchline after input.
3. Book Manager — loads book records into Book objects and supports listing, lookup, borrowing, and returning books during the session.

AI assistance is disclosed in comments in the relevant source files. The assessment documentation must also include the required acknowledgement.
